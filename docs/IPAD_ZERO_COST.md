# ققنوس روی آیپد — همیشه روشن، بدون VPS، بدون هزینه، **بدون مرج**

## فضای جدا (قانون اول)
- **هیچ فایلی به `main` مرج نمی‌شود.** کد روی شاخهٔ `cursor/phoenix-signal-panel-69df` می‌ماند؛ دیتا روی شاخهٔ `phoenix-memory`.
- cron گیت‌هاب فقط روی شاخهٔ پیش‌فرض کار می‌کند، پس از cron استفاده نمی‌کنیم. هر ایجنت **خودگردان** است:
  در پایان هر اجرا، اجرای بعدیِ خودش را روی همین شاخه dispatch می‌کند و اجرای بعدی به اندازهٔ چرخه صبر می‌کند (`scripts/loop.sh`).
  ریپو عمومی است → دقیقهٔ Actions رایگان و نامحدود است.
- سه ایجنت همدیگر را زنده نگه می‌دارند: اگر حلقهٔ یکی بمیرد (لغو، تایم‌اوت، قطعی گیت‌هاب)، دو ایجنت دیگر در اجرای بعدی‌شان آن را روشن می‌کنند.
  فقط اگر هر سه هم‌زمان بمیرند، یک کلیک «Run workflow» از روی آیپد کافی است.
- هیچ workflow، فایل یا پنل دیگری در ریپو لمس نمی‌شود.

## راه‌اندازی (یک‌بار، از روی خودِ آیپد در مرورگر) — بدون مرج
1. **Actions → "Phoenix 1 · Scan + Organization → Pages" → Run workflow → Branch: `cursor/phoenix-signal-panel-69df`** (delay_min = 0).
   از همین لحظه حلقه شروع می‌شود و خودش Phoenix 2 و 3 را هم روشن می‌کند. (می‌توانی آن دو را هم دستی بزنی.)
2. برای دیدن صفحه: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   اگر انتشار با پیام «environment protection rules» رد شد: **Settings → Environments → github-pages → Deployment branches**
   → شاخهٔ `cursor/phoenix-signal-panel-69df` را اضافه کن. (تا آن زمان اسکن، حافظه و تلگرام کار می‌کنند؛ فقط انتشار صفحه رد می‌شود، نه اسکن.)
3. روی آیپد باز کن: `https://tradeosuli-hub.github.io/Crypto-agent-server/`
   سپس **Share → Add to Home Screen** تا مثل اپ باز شود.

### چطور بفهمم حلقه زنده است؟
Actions → هر سه Workflow باید همیشه یک اجرای «in progress» (در حال صبر برای چرخهٔ بعد) داشته باشند.
تب «عیب‌یابی» داشبورد هم دو بررسی «حلقهٔ اسکن» و «حلقهٔ اطلاعات» را نشان می‌دهد؛ `/status` در تلگرام همین را می‌گوید.

## Secrets (Settings → Secrets and variables → Actions)
| نام | لازم؟ | کار |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | برای تلگرام | توکن بات از BotFather |
| `TELEGRAM_CHAT_ID` | برای تلگرام | chat_id خودت (از `@userinfobot`)؛ بات فقط به همین chat جواب می‌دهد |
| `XAI_API_KEY` | اختیاری | مغز Grok (`grok-4-fast`) + جست‌وجوی زندهٔ X برای نبض سوشال و خلاصهٔ فارسی خبر |
| `OPENAI_API_KEY` | اختیاری | مغز جایگزین اگر Grok نبود |

بدون کلید مغز، همه‌چیز قاعده‌محور کار می‌کند؛ هیچ ایجنتی متوقف نمی‌شود.

## دستورات بات تلگرام (هر ۱۵ دقیقه خوانده می‌شود)
- `/status` — سلامت سه ایجنت + شمارنده‌ها
- `/signals` — معاملات باز
- `/close ID TP|SL [R]` — ثبت دستی نتیجه (در چرخهٔ بعدی اسکن اعمال می‌شود)
- `/help`

## محدودیت‌های صادقانه
- چرخهٔ اسکن ≈ ۱۰ دقیقه (۹ دقیقه صبر + ~۱ دقیقه اجرا) به‌علاوهٔ صفِ Actions؛ تصمیم ۱۵دقیقه‌ای متد با آن سازگار است، ولی ماشهٔ ۵دقیقه‌ای ممکن است با تأخیر دیده شود.
- دستورات تلگرام با تأخیر تا ۱۵ دقیقه پاسخ می‌گیرند (بات سرور ندارد).
- وقتی Actions دیر اجرا شود یا حلقه‌ای بمیرد، نشانِ وضعیت در صفحه زرد/قرمز می‌شود و واچ‌داگ/ایجنت‌های دیگر آن را زنده می‌کنند.
- حلقهٔ خودگردان به GitHub وابسته است؛ در قطعی سراسری GitHub همه‌چیز می‌ایستد و بعد از برگشت، اولین ایجنتی که اجرا شود بقیه را روشن می‌کند.
- اگر روزی خواستی تأخیر صفر داشته باشی، همین کد با `scripts/watchdog_forever.py` روی هر سرور همیشه‌روشنی هم اجرا می‌شود (docs/ALWAYS_ON.md).
