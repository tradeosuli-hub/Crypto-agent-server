- این پنل کاملاً مستقل است و به هیچ پنل دیگری دست نمی‌زند.

## تب‌های داشبورد
| تب | محتوا |
|---|---|
| نمای کلی | KPIها، نبض بازار (دامیننس، ترس‌وطمع، ترند)، ۴۸ ساعت اخیر، سلامت ایجنت‌ها |
| سیگنال‌های واقعی | فقط SIGNALهای تأییدشدهٔ سازمان + معاملات باز + دفترچه |
| همهٔ ارزها | کارت هر ارز با رأی شورا، پارامترها، آلارم‌ها (فیلتر SETUP/WATCH/FLAT/BLIND) |
| سازمان | جریان تصمیم، تابلوی دپارتمان‌ها، ماتریس رأی هر ارز |
| خبر و رویداد | خبرها با نوع/اهمیت، رویدادهای اختصاصی هر ارز، نبض X |
| عیب‌یابی | بررسی‌های واچ‌داگ، رخدادهای باز (با لاگ و تشخیص مغز)، تاریخچه، اجراهای اخیر |
| حافظه و تجربه | شمارنده‌ها، تجربه‌ها، دقت دپارتمان‌ها به تفکیک رژیم، ممیزی‌ها، معاملات بسته |

## راه‌اندازی (یک‌بار، از روی خودِ آیپد در مرورگر)
1. این شاخه را به `main` مرج کن (زمان‌بندی GitHub فقط روی شاخهٔ پیش‌فرض اجرا می‌شود).
2. در ریپو: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   (تا فعال نشود، اسکن و یادگیری انجام می‌شود ولی صفحه منتشر نمی‌شود؛ workflow با هشدار رد می‌شود نه خطا.)
3. **Actions → "Phoenix 1 · Scan + Organization → Pages" → Run workflow** تا اولین اسکن منتشر شود.
   Phoenix 2 و 3 را هم یک‌بار دستی اجرا کن.
4. روی آیپد باز کن: `https://tradeosuli-hub.github.io/Crypto-agent-server/`
   سپس **Share → Add to Home Screen** تا مثل اپ باز شود.

## Secrets (Settings → Secrets and variables → Actions)
| نام | لازم؟ | کار |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | برای تلگرام | توکن بات از BotFather |
| `TELEGRAM_CHAT_ID` | برای تلگرام | chat_id خودت (از `@userinfobot`)؛ بات فقط به همین chat جواب می‌دهد |
| `XAI_API_KEY` | اختیاری | مغز Grok (`grok-4-fast`) + جست‌وجوی زندهٔ X برای نبض سوشال و خلاصهٔ فارسی خبر |
| `OPENAI_API_KEY` | اختیاری | مغز جایگزین اگر Grok نبود |

بدون کلید مغز، همه‌چیز قاعده‌محور کار می‌کند؛ هیچ ایجنتی متوقف نمی‌شود.

## دستورات بات تلگرام (هر ۱۵ دقیقه خوانده می‌شود)
- `/status` — سلامت سه ایجنت + شمارنده‌ها
- `/signals` — معاملات باز
- `/close ID TP|SL [R]` — ثبت دستی نتیجه (در چرخهٔ بعدی اسکن اعمال می‌شود)
- `/help`

## محدودیت‌های صادقانه
- زمان‌بندی GitHub حداقل ۵ دقیقه است و گاهی چند دقیقه تأخیر دارد؛ تصمیم ۱۵دقیقه‌ای متد با چرخهٔ ۱۰ دقیقه سازگار است، ولی ماشهٔ ۵دقیقه‌ای ممکن است با تأخیر دیده شود.
- دستورات تلگرام با تأخیر تا ۱۵ دقیقه پاسخ می‌گیرند (بات سرور ندارد).
- وقتی Actions دیر اجرا شود، نشانِ وضعیت در صفحه زرد/قرمز می‌شود و واچ‌داگ وارد می‌شود.
- اگر روزی خواستی تأخیر صفر داشته باشی، همین کد با `scripts/watchdog_forever.py` روی هر سرور همیشه‌روشنی هم اجرا می‌شود (docs/ALWAYS_ON.md).
